# 发布隐私白名单

发布采用新目录与精确文件清单，不从工作目录直接整体提交，也不携带既有 Git 历史。

## 允许上传

- 本次新写的 README、分析、验证和隐私说明。
- 五个补丁的明确列出的 Java 源文件、Fabric/Mixin 配置、构建脚本及项目许可证。
- 明确列出的测试源码和测试脚本；其中玩家标识及日期为合成测试数据。
- 五个指定版本的补丁 JAR、SHA-256 校验清单。
- 隐私检查脚本、拒绝其他文件的 gitignore 和 `PUBLIC_FILES.json`。

`PUBLIC_FILES.json` 列出精确路径和 SHA-256。该清单自身作为唯一额外的发布元数据文件，不能自包含其自身摘要。上传进程只发送清单文件和这些列出的字节；远端再次核对完整文件集合及 Git blob 摘要。

## 一律排除

原始 HPROF、数据库及侧文件、数据库备份、玩家存档、日志/压缩日志、世界目录、原模组归档、第三方 JAR、依赖缓存、构建中间产物、旧内部报告、审查证据、凭据/认证配置、环境文件、本机路径和既有 Git 历史。

## 内容检查

扫描允许文件的文字内容，并展开 JAR 检查所有条目。JAR 仅允许项目自身类、必要的 Fabric/Mixin JSON、项目许可证和 Manifest；解析 class 的 UTF-8 常量池检查敏感内容。拒绝令牌格式、私钥头、邮件地址、非测试 UUID、本机绝对路径与非本机 IPv4 地址。清单中的 SHA-256 是校验元数据，不是凭据。

只有本机测试地址 `127.0.0.1` 允许出现在测试脚本中。真实服务器地址、玩家名、玩家 UUID、世界坐标样本、堆地址、原始运行日期均不进入文档。通用代码中的区块坐标和合成测试坐标不属于生产数据。

GitHub 仓库账号与用户指定的 noreply 提交邮箱属于获授权的提交元数据；凭据仅在上传进程内存中使用，不进入仓库、环境文件、远端 URL 或提交历史。仓库默认设为私有，但检查仍按公开发布要求执行。仓库内没有包含凭据。

本检查覆盖实际白名单载荷，不是对用户其他目录或第三方模组的全面安全审计。

## 后续更新与历史保留

后续补充、更正使用普通追加提交，保留既有内容与提交历史，不通过强制推送重写历史。仅为处理真实隐私泄露时才考虑最小范围的历史清理，并明确说明原因。本次更正不涉及隐私历史清理。

新增实验材料仍须逐文件加入白名单。本次仅增加文字说明、合成场景的聚合数值和技术类摘要；原始实验日志与第三方JAR不上传。
