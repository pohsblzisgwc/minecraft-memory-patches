# 验证结果与复现边界

## 已完成的验证

基于 Minecraft 26.3、Java 25、Fabric Loader 0.19.5，加载五个补丁和本地合法提供的模组集，完成隔离服回归。测试集因版本声明不兼容排除了两个附加模组；不把该结果描述为对任意生产模组全集的保证。

| 检查 | 结果 |
| --- | --- |
| 地图移除、清理及防止重新入表 | 通过 |
| 假人正常网络注销 | 会话集合回到基线，事件发生 |
| 假人断开回调抛异常 | 异常保留，集合清理、通道关闭、重复调用幂等 |
| TIS 日志关闭的主/工作线程构造 | 无遗留，工作线程错误和超时也会导致测试失败 |
| TIS 日志开启、跨线程构造/入世 | 原线程不保留烟花上下文 |
| Arrow、Snowball 日志 helper 的实体身份 | 与原实体相同 |
| 未入世 Arrow 的弱引用回收 | 通过 |
| Ledger 两种丢弃策略，各 32 线程 × 500 轮 | cap=25，peak=25，零超限；动作身份和顺序符合策略 |
| ConfluxMap 发布坐标、键、ticket、band | 逐项对照原读取路径通过 |
| ConfluxMap 两订阅者、2125 项轮转、卸载重载、空桶/clear | 通过 |
| SQLite 恢复独立测试 | 28 项断言通过 |
| SQLite 损坏文件、缺表文件启动恢复 | 自动备份、原生重建六表、新库可读写；两轮全部回归通过 |

原模组集有已存在的 overwrite warning。本补丁未出现致命 Mixin 注入失败；不能因此声称整个模组集“零冲突”。

## 复现

使用 README 中的环境变量配置；本项目不会下载或发布服务端和第三方模组。执行：

```bash
bash tests/database-recovery/verify.sh
RECOVERY_FIXTURE=corrupt bash tests/verify-harness/verify-all.sh
RECOVERY_FIXTURE=missing DROP_OLDEST=true bash tests/verify-harness/verify-all.sh
```

独立测试会创建临时 SQLite 文件，使用 Python 子进程验证外部锁。集成测试只向新建的临时世界写入损坏/缺表样本，不使用已有世界；游戏连接端口绑定本机。仍需留意本地提供的第三方模组可能启动其他服务或更新检查。

集成测试的 `ALL_REGRESSION_CHECKS_PASSED` 在所有补充检查之后输出。原始日志含路径、运行环境和第三方输出，因此没有上传；公开内容为测试源码及脱敏断言总结。测试中的玩家名、UUID 派生字符串及日期都是合成数据。
